# Exercise 2

Quick Start Guide:

1. Install Node.js 18 or newer.
2. Download the exercise.json file and place it in the same folder of the js files
3. Stop words are read from `../stop_words.txt`.

```bash
node exc2-04.js pride-and-prejudice.txt
node exc2-05.js pride-and-prejudice.txt
node exc2-06.js pride-and-prejudice.txt
```
